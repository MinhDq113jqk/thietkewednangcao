# Thư mục lưu ảnh minh chứng bài tập nhóm

Lưu các ảnh chụp màn hình vào thư mục này để tự động hiển thị trong file `README.md` chính:

1. `cau3_database.png`: Ảnh chụp màn hình hệ quản trị CSDL (pgAdmin / DBeaver / Docker) hiển thị database `souvenirshop` và các bảng.
2. `cau4_dbconnection.png`: Ảnh chụp màn hình chạy lệnh `node dbconnection.js` thông báo kết nối CSDL thành công.
3. `cau5_crud_sv1.png`: Ảnh chụp màn hình CRUD đối tượng `Product` của Sinh viên 1.
4. `cau5_crud_sv2.png`: Ảnh chụp màn hình CRUD đối tượng `User` của Sinh viên 2.
5. `cau5_crud_sv3.png`: Ảnh chụp màn hình CRUD đối tượng `Shop` của Sinh viên 3.
6. `cau5_crud_sv4.png`: Ảnh chụp màn hình CRUD đối tượng `Order` của Sinh viên 4.
