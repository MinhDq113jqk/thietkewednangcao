# API SouvenirShop

- Mở [index.html](index.html) để xem và tìm các API theo chức năng.
- [openapi.json](openapi.json) là đặc tả OpenAPI 3.0.3, có thể nhập vào Postman hoặc Swagger Editor.
- API khi chạy local: `http://localhost:3000`.

Tài liệu có phương thức, đường dẫn, dữ liệu gửi lên, phản hồi và yêu cầu xác thực cho 122 endpoint. Các ví dụ dùng dữ liệu minh họa.

Tạo lại tài liệu sau khi sửa API:

```powershell
npm --prefix backend run docs:api
```
